# Coin Maze

A simple 2D platformer game made with Godot 4.

## About the Game

Coin Adventure is a platform game where the player jumps across platforms and collects coins.

This version currently includes:
- 1 playable level
- Coin collection system
- Score counter
- Animated player
- Platform movement and jumping

## Gameplay

The goal is to:
1. Collect coins
2. Explore the level
3. Avoid falling off the map

---

## Controls

| Key | Action |
|---|---|
| Left Arrow / A | Move Left |
| Right Arrow / D | Move Right |
| Space | Jump |

---

- 2D platformer movement

## How to Run

1. Download or clone the repository
2. Open the project in Godot 4
3. Open `project.godot`
4. Press the Play button
